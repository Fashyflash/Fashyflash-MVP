# Fashyflash-MVP
FashyFlash helps independent fashion labels turn garment photos into AI-generated product imagery: upload, set creative details, render, curate, and export. Built at the AI.WOMEN Hackathon, with a broader vision for one product record powering every channel.

## Current scope and future vision

FashyFlash currently proves the first working image workflow only: garment photos to selected JPG/PNG image exports.

The same product record could later support further content channels, such as social media, online-shop content and digital showroom platforms. These are future possibilities, not features implemented in this hackathon prototype.

## Workflow
Upload garment photos.
Add the product category and creative settings.
Save one product record and generate image options.
Review the AI-generated images in the media library.
Select the final images.
Export selected assets as JPG or PNG.
Each step uses the same saved product record, keeping source images, creative settings, generated media and selection state connected.
